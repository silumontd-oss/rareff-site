Privacy Policy

Last updated: October 1, 2026

1. About RaReff

RaReff is a personal drawing reference application developed by Rakuti Studio.

RaReff is designed to help users organize and display visual references for drawing.

2. Local Files

RaReff can use images selected by the user from local storage or supported device storage locations.

These files are selected and controlled by the user. RaReff does not upload local reference images to Rakuti Studio servers.

3. Pinterest Integration

If Pinterest integration is enabled and available, RaReff may access Pinterest data after the user explicitly authorizes the application through Pinterest's official authorization flow.

The intended Pinterest integration is limited to accessing the authenticated user's own Pinterest Boards and Pins for use as visual references within RaReff.

RaReff does not use Pinterest Search, scraping, or unauthorized access to other users' Pinterest content.

4. Pinterest Authentication Data

When Pinterest integration is used, authentication information provided by Pinterest is used only to perform authorized API requests on behalf of the user.

Authentication credentials and access tokens are not intentionally exposed publicly or included in the application's source code.

5. Data Storage

RaReff is designed primarily as a local application. Data required for the application's local functionality may be stored on the user's device.

RaReff does not operate a general-purpose cloud service for storing users' drawing references.

Pinterest-related data storage and caching are subject to the permissions and requirements applicable to the Pinterest API and may be limited or disabled where required.

6. Data Sharing

Rakuti Studio does not sell users' personal information.

RaReff does not intentionally share users' Pinterest credentials or access tokens with unrelated third parties.

When Pinterest integration is used, requests to Pinterest are made through Pinterest's API as required to provide the authorized functionality.

7. User Control

Users control whether they connect their Pinterest account to RaReff.

Users may stop using the Pinterest integration and revoke the application's authorization through the controls provided by Pinterest.

8. Security

Rakuti Studio takes reasonable measures to protect application credentials and authentication information used by RaReff.

9. Changes to This Policy

This Privacy Policy may be updated when RaReff's functionality, data handling practices, or applicable requirements change.

10. Contact

For privacy-related questions regarding RaReff, contact Rakuti Studio through the contact information associated with the application.

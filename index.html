RaReff

RaReff is a personal drawing reference application developed by Rakuti Studio.

It helps users organize and display visual references for drawing, including references from local files and, where supported, the user's own authorized Pinterest Boards and Pins.

Pinterest Integration

When Pinterest integration is available, RaReff accesses Pinterest content only through Pinterest's official API and only after the user authorizes access to their own Pinterest account.

RaReff does not provide Pinterest Search, scraping, or access to other users' private Pinterest content.
